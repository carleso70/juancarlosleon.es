Un informe de SEO tiene partes bien definidas: estado actual, deficiencias y recomendaciones. Eso lo convierte en el candidato perfecto para trabajar con IA. No para que la IA piense por ti, sino para que estructure y redacte lo que tú ya sabes interpretar.

Esta receta te da el prompt base, te explica cómo usarlo y muestra el resultado con una web real.

## Los ingredientes

- La URL de la web a analizar
- Datos de Google Search Console o Analytics (clics, impresiones, CTR, posición media, queries principales, páginas con más tráfico)
- Claude, ChatGPT o cualquier modelo con contexto largo

## El prompt

```
Eres un consultor SEO senior con experiencia en presentar 
resultados tanto a perfiles técnicos como a ejecutivos de negocio.

Voy a proporcionarte:
- La URL de la web a analizar
- Datos de Google Search Console / Analytics (los pegaré directamente)

Genera un informe SEO estructurado en tres secciones:

1. ESTADO ACTUAL
   Resumen ejecutivo del rendimiento orgánico: visibilidad, 
   tráfico, páginas indexadas, keywords posicionadas. 
   Tono claro, sin jerga técnica. Máximo 3 párrafos.

2. DEFICIENCIAS
   Lista priorizada de problemas detectados, ordenados por 
   impacto. Para cada uno: qué es, por qué importa, 
   evidencia en los datos.

3. ASPECTOS A MEJORAR
   Recomendaciones accionables, separadas en dos bloques:
   - Rápidas (se pueden aplicar esta semana)
   - Estructurales (requieren planificación o desarrollo)

El informe debe ser legible por un ejecutivo de cuentas 
y útil para un desarrollador. Evita relleno. 
Sé directo y específico.

URL: [PEGAR AQUÍ]
Datos: [PEGAR AQUÍ]
```

*Ejemplo con www.carleso.com — en cuanto tengamos datos de GSC completamos esta sección.*

## Cómo personalizarlo

El prompt base funciona, pero mejora cuando añades tu criterio:

- **Define umbrales propios:** "considera crítico cualquier CTR por debajo del 2%" 
- **Ajusta el tono al cliente:** añade "el cliente es una PYME del sector hostelero sin equipo técnico interno"
- **Pide formato específico:** "el informe se presentará en PowerPoint, usa bullet points cortos"

Con el tiempo, este prompt se convierte en tu plantilla de trabajo — y cada informe te lleva minutos, no horas.
